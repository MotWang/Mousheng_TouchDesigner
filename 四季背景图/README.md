## 规格

- **分辨率**：1920 × 1080
- **比例**：16:9
- **格式**：PNG
- **风格**：吴冠中-inspired + 宋代院体画融合
- **质感**：宣纸纹理，轻微纸纤维感

---

## 设计规范

### 黑白层（Mono）
- 纯黑白水墨效果
- 由对应彩色图实时去色生成（TD工程内）
- 像素严格对齐彩色层

### 彩色层（Color）
- 工笔重彩风格
- 矿物颜料质感
- 金色点缀
- 与黑白层像素严格对齐
