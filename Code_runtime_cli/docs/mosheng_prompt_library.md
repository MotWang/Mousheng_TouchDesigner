# 《墨·生》AI 素材 Prompt 库

## 使用方式

每个季节至少产出一组“同构图、同尺寸、同画布比例”的黑白和彩色图片。建议先生成彩色主图，再用同一 seed / reference image 生成黑白版本，最后统一裁切并输出到 `assets/mosheng/images/`。

命名必须与 TD 工程一致：

- 黑白层：`spring_mono.png`、`summer_mono.png`、`autumn_mono.png`、`winter_mono.png`
- 彩色层：`spring_color.png`、`summer_color.png`、`autumn_color.png`、`winter_color.png`

## 基础主 Prompt

Chinese ink wash interactive installation artwork, elegant ancient Chinese screen painting, xuan paper texture, poetic negative space, Wu Guanzhong inspired rhythm of dots lines and planes, quiet and dynamic balance, refined composition, high detail

## 黑白版本后缀

ink wash painting, monochrome, no color, xuan paper, minimal, soft ink diffusion, elegant blank space

## 彩色版本后缀

vibrant Chinese gongbi color, rich mineral pigment, subtle gold accents, elegant saturated color, same composition as reference image

## 四季关键词

Spring: peach blossom, willow, light mist, tender green, flowing water

Summer: lotus pond, kingfisher, lush leaves, warm wind, bright pigment

Autumn: red maple, crane, distant mountain, golden dusk, dry brush texture

Winter: plum blossom, snow, pale moon, cold ink, quiet blue grey

## 微动态视频指令

Extremely subtle motion, slow loop, no camera movement, gentle ink diffusion, slight cloth breathing, tiny petal movement, calm and meditative, seamless 8 second loop

## 负面约束

no modern object, no neon, no western oil painting, no aggressive animation, no fast camera movement, no text, no logo, no distorted face
