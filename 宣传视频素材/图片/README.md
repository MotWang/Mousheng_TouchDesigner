## 建议筛选

### 宣传视频推荐选用（2:00-2:20 段落）

**必选类型：**
1. **全景照**（2张）：整个展览空间，投影+观众位置
2. **互动照**（3张）：观众挥手 + 画面显色同框
3. **细节照**（2张）：投影画面特写，水墨质感
4. **氛围照**（2张）：观众背影、多人互动、展览入口

### 使用建议
- 每张停留 3-4 秒
- 转场用淡入淡出
- 统一调色：偏暖色调，增加颗粒感
