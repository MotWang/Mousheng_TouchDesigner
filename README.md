# 《墨·生》项目集合

> 人未动，画为静；人一动，墨生色，画成境。  
> 以吴冠中「动与静」为审美内核的交互水墨投影装置。

## 项目简介

《墨·生》是一套以 TouchDesigner 为核心的交互装置与展陈资料集合。  
观众在摄像头前的动作会被实时映射为水墨显色轨迹：静止为黑白留白，动作即触发彩色透出；当显色覆盖达到阈值后，触发四季绽放与换季过渡。

该仓库不仅包含实时工程，也包含素材、音效、现场执行文档与宣传视频制作资料，适用于以下场景：

- 展览现场部署与调试
- 课程/答辩演示与项目归档
- 二次创作（视觉、声音、视频剪辑）

## 核心技术

- 实时引擎：TouchDesigner
- 动作捕捉：Optical Flow 光流
- 视觉机制：黑白/彩色双层叠加 + 墨色累积 + Feedback 晕染
- 音画联动：交互音效与季节转场
- 输出规格：16:9 投影画面（工程内可调分辨率）

## 快速开始

### 1) 打开工程

- 推荐直接打开 `Code/mosheng_final.toe`（若该文件为当前可执行版本）
- 若你在 `Code` 下维护脚本，可在 TouchDesigner 的 Text DAT 中运行 `Code/td/` 里的脚本进行重建或增量更新

### 2) 检查关键流程

- `01_camera_motion_mask`：动作采样与蒙版生成
- `02_visual_assets`：四季黑白/彩色素材管理
- `03_ink_reveal_composite`：显色叠加与墨晕
- `04_audio_reactivity`：交互音效触发
- `07_grade_and_frame`：最终调色与输出

### 3) 现场验证建议

- 冷启动后先确认黑白基底正确
- 挥手测试显色累积与残留
- 达阈值后检查换季是否完整触发
- 确认投影画幅、亮度与无黑边输出

## 四季交互效果

- 春：柳叶轻盈飘落，画面疏朗
- 夏：荷瓣上浮，金色辉光增强
- 秋：枫叶与金尘扩散，层次更暖
- 冬：雪花渐覆，回归素静

## GitHub 上传说明（重要）

本项目包含大体积媒体文件，其中 `墨生_宣传视频.mov` 约 290MB，超过 GitHub 单文件 100MB 限制。  
如果直接上传，推送会失败。建议二选一：

- 轻量版（推荐）：忽略超大源文件，仅上传工程与可复现实验资料
- 完整档案版：启用 Git LFS 后上传大文件

当前仓库已按轻量版思路准备（可在根 `.gitignore` 控制）。
