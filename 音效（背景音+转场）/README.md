## 格式

- **格式**：MP4（音频）
- **采样率**：44.1kHz
- **位深**：16-bit

---

## 使用建议

### 音量配比
- 背景环境音：-20dB ~ -15dB
- 交互音效：-10dB ~ -5dB
- 转场音效：-5dB ~ 0dB

### 触发逻辑
- 小动作 → 极淡笔触声
- 大动作 → 墨晕染声 + 音量增大
- 绽放触发 → 对应季节花开/叶落声
